核心能力

从概念配图到精确矢量流程图，从数据可视化到图像复现，全方位覆盖科研图像需求

四大生成模式

一条命令，覆盖科研图像全场景

01

文生图模式

image

基于智谱 Cogview-3-Flash 免费接口，LLM 动态生成高质量 Prompt，支持通用艺术风格和顶会流程图风格。

$ scicovergen paper.md --mode image --style conference_diagram
02

代码精确绘图

diagram

LLM 提取论文算法架构，Matplotlib 渲染精确矢量流程图。文字清晰可读，300dpi 直接投稿。

$ scicovergen paper.md --mode diagram
03

数据转绘图

data_plot

JSON 数据输入，8 种顶会预建风格自动渲染。支持配对对比柱、置信区间带、t-SNE 聚类、雷达图等。

$ scicovergen data.json --mode data_plot --plot-style bar_paired_delta
04

图像复现

image_repro

上传参考配图，PIL 分析比例/颜色/布局，LLM 生成 matplotlib 复现代码，一键还原顶会风格图表。

$ scicovergen reference.png --mode image_repro

设计理念

SciCoverGen 并非简单的 API 封装，而是将学术界的视觉规范工程化。 我们从 NeurIPS、ICML、ICLR 等顶会论文中提取配色体系、字体规范、布局美学， 结合国内免费大模型的文本理解与图像生成能力，构建了一套完整的科研图像生成流水线。 无论是概念配图、算法流程图、实验图表还是图像复现，都能输出可直接用于投稿的高质量成果。

快速开始

三步启动，即刻生成科研配图

1

安装

$ pip install scicovergen
2

配置 API Key（免费）

$ export ZHIPU_API_KEY=your-api-key

在 智谱开放平台 免费注册获取 API Key

3

运行命令生成图像

以下命令均读取本地文件，无需上传。准备好对应的输入文件后，任选一条在终端执行即可：

# 论文概念配图（输入：本地文本/MD 文件）
scicovergen paper.md --mode image --style conference_diagram
# 精确矢量流程图（输入：含算法描述的文本）
scicovergen paper.md --mode diagram
# 实验数据图表（输入：JSON 数据文件）
scicovergen data.json --mode data_plot --plot-style bar_paired_delta
# 图像风格复现（输入：参考 PNG 图片）
scicovergen ref.png --mode image_repro

Python API

如果你更习惯在 Python 脚本或 Jupyter Notebook 中调用，可以直接使用 Python API，功能与命令行完全一致：

from scicovergen import SciCoverGen, PlotGenerator, PlotReproducer

# 统一入口（功能与 CLI 相同）
gen = SciCoverGen(api_key="your-key")
gen.generate("paper.md", mode="diagram")
gen.generate(data_dict, mode="data_plot", style="scatter_tsne_cluster")
gen.generate("ref.png", mode="image_repro")

# 底层引擎直接调用
PlotGenerator().generate(data, "line_confidence_band", "out.png")
PlotReproducer().reproduce("ref.png", "out.png", use_llm=True)
