# GraphTransformer: 基于图 Transformer 的分子性质预测

## 研究亮点

1. **全新架构**：首次将 Transformer 注意力机制与图神经网络结合用于分子表示学习
2. **SOTA 性能**：在 QM9、MoleculeNet 等基准数据集上达到当前最优水平
3. **可解释性**：注意力权重可视化揭示分子关键子结构对性质预测的贡献
4. **高效训练**：引入虚拟节点和层次化池化，训练速度提升 3 倍
5. **开源发布**：代码和预训练模型已开源，支持一键复现

## 方法概述

### GraphTransformer 架构

- **节点编码器**：基于自注意力的图卷积层
- **边编码器**：化学键类型嵌入 + 距离感知注意力
- **全局读出**：虚拟节点聚合分子级表示

### 关键创新

1. 多头图注意力机制
2. 化学感知的相对位置编码
3. 层次化子图池化

| QM9 | MAE | 0.023 | 0.031 |
| ESOL | RMSE | 0.512 | 0.687 |
| FreeSolv | RMSE | 0.854 | 1.123 |
